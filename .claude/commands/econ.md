---
description: Пересчитать юнит-экономику под гипотезы и дать тезисы для питча
argument-hint: <гипотезы: CAC, цена, конверсии, churn…>
---

Гипотезы: $ARGUMENTS

1. Открой `config/app.config.ts`, блок `econ`. Обнови параметры по гипотезам (не заданные — оставь, но перечисли допущения).
2. Формулы лежат в `lib/econ.ts` (`calcEconomics`): pay-rate = CR в триал × CR триал→оплата; CAC платящего = CAC / pay-rate; LTV = цена × маржа / churn; LTV/CAC; окупаемость = CAC платящего / (цена × маржа).
3. Выведи таблицу «было → стало»: CAC, CR в триал, CR в оплату, цена, churn, маржа → pay-rate, CAC платящего, LTV, LTV/CAC, окупаемость (мес).
4. Дай 3 ключевых тезиса для питча (каждый — одно предложение с числом) и один главный рычаг роста (что даст максимальный прирост LTV/CAC).
5. Укажи, где модель хрупкая (какой параметр — самый неопределённый) и как мы его проверим.
6. `npm run config:check`, `npm run build`, коммит `econ: update unit economics`.
