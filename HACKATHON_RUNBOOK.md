# HACKATHON_RUNBOOK — адаптация под кейс за 30 минут

## 0. За день до хакатона (10 минут)
- [ ] `npm install`, `npm run dev`, пройти путь руками: лендинг → квиз → результат → пейволл → покупка → `/admin`.
- [ ] Ключи в `.env.local`: Anthropic (баланс пополнен), Supabase (выполнен `0001_init.sql`, включены Anonymous sign-ins и Email), `ADMIN_PASSWORD`.
- [ ] Проверить реальный AI: `DEMO_MODE=false` → пройти квиз → `provider` в `/api/health` и результат не mock.
- [ ] Деплой: `/ship`. Записать прод-ссылку.
- [ ] `git tag baseline` — точка отката к нейтральной заготовке Lumi.

## 1. Адаптация (30 минут)
| Мин | Действие |
|---|---|
| 0–5 | Запустить `/adapt-case <вставить текст кейса целиком>`. Прочитать 3 идеи. |
| 5–8 | Выбрать идею (критерии: боль пользователя > вау-AI > реализуемость за 12 ч > монетизация). |
| 8–20 | Claude переписывает `/config`: бренд, квиз, промпт+схема, mock, тарифы, тексты. Пока идёт — открыть `/` и `/quiz`, проверять тексты. |
| 20–25 | `npm run config:check && npm run build && npx playwright test`. Починить селекторы в `tests/smoke.spec.ts`, если сменились тексты кнопок. |
| 25–30 | Реальный AI-прогон с `DEMO_MODE=false`; если результат плохой — править ТОЛЬКО `config/prompts/analyze.ts`. Коммит. |

Что обязательно проверить глазами: заголовок лендинга, первый вопрос квиза, заголовок результата, тарифы, цифры `/admin`.

## 2. После адаптации
1. `/econ <гипотезы по CAC, цене, конверсиям, churn>` — получить таблицу и 3 тезиса.
2. `/pitch` — `docs/PITCH.md`; прогнать вслух с таймером (3:00).
3. `/creative` — `docs/CREATIVES.md`.
4. `/ship` — прод-ссылка + smoke на проде.

## 3. Чек-лист демо (за 10 минут до выхода)
- [ ] Открыть `/api/health` (ok=true), `/`, `/admin` — прогреть холодный старт.
- [ ] `DEMO_MODE`: для сцены безопаснее `true` (мгновенный стабильный ответ); `false` — только если реальный AI проверен вчера.
- [ ] Заранее залогиниться в `/admin` в отдельной вкладке.
- [ ] Быстрый проход квиза ≈ 40 секунд: выбираем первые варианты, слайдер по умолчанию, текст и фото пропускаем.
- [ ] Вкладка с `/paywall?v=b` для показа A/B.
- [ ] Включена зарядка/мобильный интернет как резерв.

## 4. План Б
| Сбой | Действие |
|---|---|
| AI не отвечает / медленно | Автоматический fallback на mock; либо `DEMO_MODE=true`. |
| Нет интернета | Локально `npm run dev`, `DEMO_MODE=true`, in-memory хранилище. |
| Упал Supabase | Убрать ключи — приложение переходит на in-memory; `/admin` показывает встроенный seed. |
| Упал Vercel | Показывать локальный `npm run dev`. |
| Сломалась адаптация | `git checkout baseline -- config` — откат конфига к Lumi. |

## 5. Что менять и что нет
Менять: всё в `config/`. Не менять без необходимости: `lib/`, `app/api/`. Если нужна новая AI-схема — править `AnalyzeResultSchema`, mock и отображение полей в `components/result/result-view.tsx`.
